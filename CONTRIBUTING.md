# Working together

## Start a change

1. Pull the latest `main` branch before starting.
2. Create a short-lived branch for one feature or fix, for example `feature/driver-tracking-ui`.
3. Keep commits focused and describe the change in plain language.
4. Push the branch and open a pull request for another group member to review.
5. Merge into `main` after review.

## Current project stage

RideUTeM is an interface-only prototype. Keep changes in the existing PHP, CSS, and JavaScript pages. Do not add sample personal records, credentials, API keys, or local configuration files to Git. The live-tracking page is a browser-only movement preview; it does not use GPS or send location data.
